### Phase 5: Publication Figures, Volcano Plots & Statistical Tables

In this final phase of the Rapid Expression Screening pipeline, you will generate publication-grade figures (volcano plots, unsupervised PCA, and top candidate heatmap), compile a structured statistical digest (`data/manuscript_digest.json`), and export complete differential expression result tables.

Target execution budget: **2–3 turns max**.

---

#### Objectives & Tasks

1. **Verify Expression Data & Tables**:
   - The modeled dataset is active in memory from Phase 4 (or call `tpa_load(source = "data/tidyproteomics_data.rds")`).
   - Confirm differential expression tables exist in `data/`:
     `expr_files <- list.files("data", pattern = "^table_.*_expression_.*[.](tsv|csv)$", full.names = TRUE)`
   - Extract top significant candidates ($|\log_2\text{FC}| \ge 1.0, q \le 0.05$) via `tpa_query_expression(log2fc_min = 1.0, significance_max = 0.05, top_n = 25)`.

2. **Generate Publication-Grade Diagnostic Figures in `data/`**:
   - **Publication Volcano Plot**:
     - Ensure volcano plots generated by `tpa_batch_analysis` or `tpa_plot(type = "volcano")` are present (`data/plot_proteins_volcano_<contrast>.png`).
   - **Cohort PCA Plot**:
     - Call `tpa_plot(type = "pca")` to generate an unsupervised cohort separation figure (`data/plot_proteins_pca.png`).
   - **Candidate Expression Heatmap**:
     - Subset the top differentially expressed genes and generate a focused heatmap:
       `tpa_plot(type = "heatmap")` (saving `data/plot_proteins_heatmap.png`).

3. **Author and Execute Reproducible Script `code/05_figures.R`**:
   - Persist an authoritative R script `code/05_figures.R` compiling the figures, exporting clean TSVs, and writing `data/manuscript_digest.json`.
   - Canonical script template:
     ```r
     #!/usr/bin/env Rscript
     suppressPackageStartupMessages({
       library(tidyproteomics)
       library(jsonlite)
       library(dplyr)
     })

     stopifnot(file.exists("data/tidyproteomics_data.rds"))
     tp_data <- readRDS("data/tidyproteomics_data.rds")

     analyses <- get_analyses(tp_data)
     contrasts <- if (nrow(analyses) > 0) unique(analyses$comparison) else character(0)

     # Export consolidated summary digest
     digest <- list(
       pipeline = "rapid_expression",
       analyte = tp_data$analyte,
       contrasts = contrasts,
       generated_at = format(Sys.time(), "%Y-%m-%dT%H:%M:%SZ"),
       figures = list.files("data", pattern = "^plot_.*[.]png$", full.names = FALSE),
       tables = list.files("data", pattern = "^table_.*[.](tsv|csv)$", full.names = FALSE)
     )
     write_json(digest, "data/manuscript_digest.json", auto_unbox = TRUE, pretty = TRUE)
     cat("Generated data/manuscript_digest.json\n")
     ```
   - Execute via `execute_command("Rscript code/05_figures.R")`.

4. **Phase Gate Verification & Completion**:
   - Verify that:
     1. `data/tidyproteomics_data.rds` exists.
     2. `data/plot_*.png` contains at least one publication figure (volcano or PCA).
     3. `data/table_*expression_*.tsv` or `.csv` exists with full test statistics.
     4. `data/manuscript_digest.json` exists on disk.
     5. `code/05_figures.R` and `logs/05_figures/console.log` exist.
   - Invoke `complete_phase`:
     `complete_phase(phaseName = "05_FIGURES", summary = "Rapid expression screening complete. Generated publication volcano plots, PCA, and top candidate heatmap. Persisted data/manuscript_digest.json, quantitative expression tables, and reproducible code/05_figures.R.")`
